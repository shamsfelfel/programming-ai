Object-Oriented Python, One Problem at a Timeالبرمجة الكائنية في بايثون، مشكلة تلو الأخرى

Every lesson starts with working code that hurts — code that duplicates, breaks on change, or cannot be reused — and then rebuilds it with the one OOP idea that fixes that exact pain. You write Python the whole way.

يبدأ كل درس بكود يعمل لكنه مؤلم — كود يتكرر، أو ينكسر عند أي تعديل، أو لا يمكن إعادة استخدامه — ثم نعيد بناءه بالفكرة الكائنية التي تعالج هذا الألم بالذات. ستكتب بايثون طوال الطريق.

Before you startقبل أن تبدأ

You need Python basics only: variables, lists, dictionaries, loops, functions and f-strings. No prior OOP knowledge is assumed. Keep a terminal or an editor open — every example is meant to be typed and run.

تحتاج فقط أساسيات بايثون: المتغيرات، القوائم، القواميس، الحلقات، الدوال والـ f-strings. لا يُفترض أي معرفة سابقة بالبرمجة الكائنية. أبقِ محرر الأكواد أو الطرفية مفتوحة — كل مثال مكتوب ليُجرَّب.

The lessonsالدروس

01

Objects & Classesالكائنات والأصناف

Parallel lists drift apart. Group data and the code that works on it into one thing.

القوائم المتوازية تنفصل عن بعضها. اجمع البيانات والكود الذي يعمل عليها في شيء واحد.

 02

State, __init__ & Methodsالحالة والمُنشئ والدوال

Half-built dictionaries and missing keys. Give every object a correct birth and a voice of its own.

قواميس ناقصة ومفاتيح مفقودة. امنح كل كائن ولادة صحيحة وصوتًا خاصًا به.

 03

Encapsulationالتغليف

A rule checked in six places is a rule broken in the seventh. Put the rule where the data lives.

قاعدة تُفحص في ستة أماكن هي قاعدة تنكسر في السابع. ضع القاعدة حيث تعيش البيانات.

 04

Abstraction & Clean Interfacesالتجريد والواجهات

When callers know your internals, you can never change them. Publish a small promise instead.

عندما يعرف المستخدمون تفاصيلك الداخلية لن تستطيع تغييرها أبدًا. انشر وعدًا صغيرًا بدلًا من ذلك.

 05

Inheritance & Compositionالوراثة والتركيب

Three classes, one copy-pasted body. Share what is common — and learn when sharing is a trap.

ثلاثة أصناف بجسد منسوخ واحد. شارك المشترك — وتعلّم متى تكون المشاركة فخًا.

 06

Polymorphism & Duck Typingتعدد الأشكال

The if/elif chain that grows with every new case. Let each object answer for itself.

سلسلة if/elif التي تطول مع كل حالة جديدة. دع كل كائن يجيب عن نفسه.

 07

Capstone: Two Styles, One Programالمشروع الختامي: أسلوبان لبرنامج واحد

A complete repair-shop program written twice — procedural and object-oriented — and compared line by line.

برنامج كامل لورشة صيانة مكتوب مرتين — بالأسلوب الإجرائي والكائني — مع مقارنة سطرًا بسطر.

Check what stuckتأكّد ممّا رسخ

Every lesson has a test of its own, sat after that lesson and nothing later. The Execution Lab replays the chapter’s trickiest programs one line at a time, and the two chapter tests cover the whole of Chapter 1 — A for the core ideas, B for the harder corners.

لكل درس اختباره الخاص، يُؤدَّى بعد ذلك الدرس ولا يفترض شيئًا بعده. ويعيد مختبر التنفيذ تشغيل أصعب برامج الفصل سطرًا سطرًا، أمّا اختبارا الفصل فيغطيان الفصل الأول كاملًا — (أ) للأساسيات و(ب) للزوايا الأصعب.

How to use this courseكيف تستخدم هذا المقرر

  • Read the problem first and try to name the defect yourself before scrolling.اقرأ المشكلة أولًا وحاول تسمية العيب بنفسك قبل المتابعة.
  • Type the starting code and run it. Feeling the bug is half the lesson.اكتب الكود الابتدائي وشغّله. الإحساس بالخلل نصف الدرس.
  • Do both exercises before opening the solution. A revealed solution teaches far less.أنجز التمرينين قبل فتح الحل. الحل المكشوف مبكرًا يعلّم أقل بكثير.
  • Use the ☰ menu to jump between lessons, ع to switch language, and ☾ to switch theme.استخدم قائمة ☰ للتنقل بين الدروس، وEN لتبديل اللغة، و☾ لتبديل الوضع الليلي.

The one-line version of the whole courseالمقرر كله في سطر واحد

Objects exist so that data and the rules about that data live in the same place, so that a change has one home instead of ten.

الكائنات موجودة لتعيش البيانات والقواعد التي تحكمها في المكان نفسه، فيصبح لأي تعديل بيت واحد بدلًا من عشرة.
