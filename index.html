Programming for AI

From Python you know to code machine learning is written inمن بايثون التي تعرفها إلى الكود الذي يُكتب به التعلّم الآلي

A course in chapters, each one a small site of its own: lessons that start from code that hurts, a test after every lesson, worked solutions, and a lab that runs the hard programs one line at a time. It is bilingual throughout, it installs on a phone, and once opened it needs no network at all.

مقرر في فصول، كل فصل موقع صغير قائم بذاته: دروس تبدأ من كود مؤلم، واختبار بعد كل درس، وحلول مفصّلة، ومختبر يشغّل البرامج الصعبة سطرًا سطرًا. المقرر ثنائي اللغة بالكامل، ويُثبَّت على الهاتف، ولا يحتاج شبكة بعد أول فتح.

The road aheadالطريق أمامنا

Each chapter is written in full before the next one starts, on the same scaffold as Chapter 1 — same lesson shape, same test engine, same offline promise.

يُكتب كل فصل كاملًا قبل أن يبدأ الذي يليه، على البنية نفسها التي بُني بها الفصل الأول — الشكل نفسه للدروس، ومحرّك الاختبارات نفسه، والوعد نفسه بالعمل دون اتصال.

    What you need before you startما تحتاجه قبل أن تبدأ

    Python basics, and nothing moreأساسيات بايثون، ولا شيء أكثر

    Variables, lists, dictionaries, loops, functions and f-strings. No object-oriented knowledge is assumed anywhere in Chapter 1 — it is what the chapter teaches. Keep a terminal or an editor open: every example is meant to be typed and run.

    المتغيرات والقوائم والقواميس والحلقات والدوال وصيغ f-strings. لا يُفترض في الفصل الأول أي معرفة بالبرمجة الكائنية — فهي ما يعلّمه الفصل نفسه. أبقِ الطرفية أو المحرر مفتوحًا: كل مثال مكتوب ليُجرَّب.

    Reading it offline, and installing itالقراءة دون اتصال والتثبيت

    • On Chrome or Edge an Install button appears in the top bar; on iPhone use Share → Add to Home Screen.     Why this course existsلماذا هذا المقرر

    Machine-learning code is not hard because the mathematics is hard. It is hard because it is written in a dialect — classes, arrays, frames, pipelines — that nobody teaches you before handing you a model to read. This course teaches that dialect, one problem at a time.

    كود التعلّم الآلي ليس صعبًا لأن الرياضيات صعبة، بل لأنه مكتوب بلهجة — أصناف ومصفوفات وجداول وخطوط معالجة — لا يعلّمك إياها أحد قبل أن يضع بين يديك نموذجًا لتقرأه. هذا المقرر يعلّم تلك اللهجة، مشكلة تلو الأخرى.
